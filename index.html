Turn three report formats into one decision.

Parsing problems stay visible as warnings while valid metrics still reach the report.

JUnit

Count passes, failures, skips, duration, failed examples, and the slowest tests.

SimpleCov

Read line coverage, calculate the percentage, and compare it with an explicit baseline.

Benchmarks

Carry named values, units, and deltas from JSON into the same build artifact.

Useful with images on or off.

PNG

Deterministic card

A stable visual artifact for history branches, pull requests, and dashboards.

Markdown

Job Summary

A readable metric table, slow tests, failures, and trend that needs no image renderer.

Build the first report.

gem install nashira
nashira build --junit "tmp/*.xml" \
  --coverage coverage/.last_run.json
